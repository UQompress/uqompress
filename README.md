# UQompress

UQCS 2026 Hackathon Project 

Cheat sheet maker for UQ courses

## Gemini API configuration

Copy `.env.example` to `.env.local`, then replace
`YOUR_GOOGLE_GEMINI_API_KEY` with a Gemini API key from Google AI Studio.
The app uses Gemini's OpenAI-compatible Chat Completions endpoint with low
reasoning effort and priority inference.
